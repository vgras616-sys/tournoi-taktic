# Tournoi Tac Tik

Appli mobile de tournoi entre amis : tables, adversaires, historique, classement à la suisse et phase finale.

- `index.html` : l'appli (configuration Firebase à remplir en haut du fichier)
- `regles-firebase.json` : règles de la Realtime Database (lecture publique, écriture réservée à l'organisateur)
